Browser integration

Extension

The browser extension sends download links to this app automatically while the app is running. The extension zip ships with this release: in Chrome open chrome://extensions, turn Developer mode ON, press Load unpacked, and select the unzipped extension folder. There are no switches here because interception is automatic — when the app is closed, the browser downloads normally. The first-run wizard repeats these steps.

Keyboard shortcuts

  • Ctrl + N — New download task
  • Space — Pause / resume the selected downloads (ignored while typing)
  • Del — Delete the selected downloads (asks first)
  • Esc — Close menus and dialogs
